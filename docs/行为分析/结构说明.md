# 项目结构规范

## 顶层目录（前后端分离）

```
market-agents/
├── 后端/                       # 后端 = pip 包 market_platform.agents（无嵌套目录）
│   ├── __init__.py
│   ├── cli.py                  # 不可改（入口）
│   ├── settings.py
│   ├── 接口/                   # FastAPI 路由 + Web 读模型
│   ├── 核心/                   # 路径、工具、通知、大模型、任务
│   ├── 采集/                   # 数据拉取（含 行业/）
│   ├── 分析/                   # 特征、推断、回测、批处理、仿真、可视化
│   ├── 存储/                   # PostgreSQL
│   ├── 配置/                   # YAML（配置档/）
│   ├── 数据/                   # 运行时 CSV
│   └── 脚本/                   # 运维脚本
├── 前端/                       # Vue 3 + Vite SPA
├── 文档/
└── pyproject.toml              # package-dir: 后端 → market_platform.agents
```

## 命名约定

| 类型 | 规则 |
|------|------|
| 目录 | 中文（`后端`、`前端`、`配置档` 等） |
| Python 包名 | `market_platform.agents` 及中文子包（`接口`、`核心` 等） |
| Python 模块文件 | 中文（`批量拉取.py`、`网页数据.py` 等） |
| 入口文件 | `cli.py`、`settings.py`、`__init__.py` 不可改 |
| 配置 YAML | 中文（`默认.yaml`、`全市场拉取.yaml`） |
| 运维脚本 | 中文（`拉取全市场.py`） |
| 测试文件 | `test_*.py`（pytest 约定，不可改） |
| 前端源码 | 中文（`源码/页面/总览.vue`、`资源/样式.css` 等） |
| 前端工具链 | 英文（`package.json`、`vite.config.ts`、`index.html`） |

## 路径约定

- `backend_root()` → `后端/`
- `frontend_dir()` → `前端/`
- `profile_path("默认.yaml")` → `后端/配置/配置档/默认.yaml`

## 入口约定

| 用途 | 命令 |
|------|------|
| 统一 CLI | `market-agents <command>` |
| API 服务 | `market-agents web` |
| 前端开发 | `cd 前端 && npm install && npm run dev` |
| 全市场拉取 | `python 后端/脚本/拉取全市场.py` |
| 全市场分析 | `python 后端/脚本/分析全市场.py` |

## import 示例

```python
from market_platform.agents.settings import AppConfig

from market_platform.agents.分析.批处理.批运行器 import run_batch

from market_platform.agents.核心.路径.项目 import data_dir, frontend_dir
```
