# 前端

Vue 3 + Vite + TypeScript 单页应用，与后端 API 分离部署。

技术栈：Vue 3、Pinia、Naive UI、ECharts（vue-echarts）。

## 依赖管理（pnpm + 全局 store）

前端**不能**像 Python `pip --user` 那样把包装进系统路径，但用 **pnpm** 可以把依赖实体放在用户目录：

- 全局 store：`~/.local/share/pnpm/store`（配置见 `.npmrc`）
- 项目内 `node_modules/` 只是链接，**可随时删除**，需要时再装回来
- 多个 Node 项目**共用同一份** store，不重复占盘

```bash
# 一次性：安装 pnpm（用户级）
npm install -g pnpm

# 项目内安装（依赖写入全局 store）
cd 前端
pnpm install

# 不开发前端时，可删掉链接目录释放项目占用
rm -rf node_modules dist
# 再用时：pnpm install（秒级，从 store 恢复）
```

## 本地开发

终端 1 — 启动后端 API（默认 `8766` 端口）：

```bash
cd .. && pip install --user -e ".[web,postgres]"
market-agents web
```

终端 2 — 启动 Vite 开发服务器（`8080` 端口，自动代理 `/api`）：

```bash
cd 前端 && pnpm install && pnpm run dev
```

浏览器打开 `http://localhost:8080`。

## 生产构建

```bash
pnpm run build
```

产物在 `dist/`（已在 `.gitignore`），可由 Nginx 等静态托管，并将 `/api` 反向代理到后端。

## 配置 API 地址

开发环境默认通过 `vite.config.ts` 将 `/api` 代理到 `http://localhost:8766`，无需额外配置。

若需直连其他后端，可设置环境变量：

```bash
VITE_API_BASE=http://your-api-host:8766 pnpm run dev
```

## 一体化模式（可选）

```bash
SERVE_FRONTEND=1 market-agents web
```

访问 `http://localhost:8766/`（后端托管已构建的 `dist/` 或静态资源）。

## 目录结构

```
源码/
├── 接口/          # API 客户端（客户端.ts）
├── 类型/          # TypeScript 类型（接口.ts）
├── 工具/          # 格式化、图表配置
├── 组件/          # 导航栏、图表容器
├── 状态/          # Pinia 状态
├── 资源/          # 全局样式
└── 页面/          # 总览 / 行业 / 标的 / 组合
```

工具链配置文件（`package.json`、`pnpm-lock.yaml`、`vite.config.ts`、`tsconfig.json`、`index.html`）保留英文命名。
