| 项 | 问题 | 处置 | 验收证据 |
|----|------|------|----------|
| R1 | `tf_proba_*` 由训练后对**全样本**推理生成(训练段是样本内预测) | 新增**走查(walk-forward)**生成:每块先用该块之前的数据重训再预测本块;关闭走查时只填 checkpoint 训练结束日之后的行,其余留空。另补 checkpoint 训练区间元数据(`train_start/train_end/train_rows/seed/feature_cols`) | `tests/平台/test_研究可信度.py` 的走查/样本外用例;真实 Transformer 集成验证:3 块、15 行有效、概率行和=1、最小训练行之前全空 |
| R2 | 默认 `split_method: cycle` 把验证集取成历史上零散周期段 → 训练集含验证期之后数据 | 新增 **`cycle_tail`**(验证集只取历史末尾连续周期段,并在切分后做因果校验,失败即回退时间切分);默认值改为 `cycle_tail`;旧 `cycle` 保留但会打前视告警 | `test_周期末尾切分_训练集严格早于验证集` |
| R3 | 月频宏观指标按"月初即可见"处理(实际次月 9~15 日发布) | `_expand_monthly_to_daily` 改为**期末 + 发布滞后**才可见且不回填;新增配置 `data.macro_publish_lag_days`(默认 15)与按列覆盖(PMI +1、LPR +20) | `test_月频宏观_发布滞后生效且不回填` |
| R4 | 行为分析每次增量对**全窗口**重拟合 NMF → 历史活跃度被改写,历史不可复现 | 新增 `追加式分解`(point-in-time):历史行**保持原值**、新增行用固定基做非负最小二乘投影;新增行数达到 `refit_every_rows` 时只用**历史窗口**重拟合基,仍不动历史行。配置 `nmf.append_only`(默认 true) | `test_追加式分解_历史活跃度保持原值` + 旧行为对照用例 |
| R5 | 全样本列 max 归一 / 全样本 StandardScaler(输入携带未来统计量) | `normalize_feature_matrix` 默认改**扩展窗口(cummax)**;`隐马尔可夫._扩展窗口标准化`;`状态.py` 规则分类同样改 cummax;保留 `full` 模式仅用于复现旧结果 | `test_扩展窗口归一化_截断未来不改变历史行`、`test_扩展窗口标准化_逐行只用历史行`、`test_全样本归一化模式确实有前视_用于对照` |
| R7 | 全仓无随机种子,`shuffle=True` 不可复现 | 新增 `core/随机.py`(python/numpy/torch + cudnn 确定性),`TransformerPredictor.train` 每次显式置种,DataLoader 用确定性 generator,走查逐块派生 `seed+块序号` | `test_种子可设定且可复现`、`test_取生成器_同种子同序列` |

**修复过程中额外发现并修掉的两个真实缺陷(已加回归测试)**

   `predict_proba_aligned` **静默返回全 NaN** —— 现改为整体透传调用方 cfg。
2. 全 NaN 的块原本仍被计入「已填行」,属静默失效 —— 现计入 `失败块` 并告警。
