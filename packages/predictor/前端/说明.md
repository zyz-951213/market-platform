# 前端

Vite 单页应用，与后端 API 分离部署。只读展示（禁止写操作）。

技术栈：原生 JavaScript + Vite + ECharts。

## 本地开发

终端 1 — 启动后端 API（默认 `8765`）：

```bash
cd .. && market-predictor web
# 或：python -m market_platform.predictor.脚本.启动Web
```

终端 2 — 启动 Vite 开发服务器（`8080`，自动代理 `/api`）：

```bash
cd 前端
npm install
npm run dev
```

浏览器打开 `http://localhost:8080`。

## 生产构建

```bash
npm run build
```

产物在 `dist/`（已在 `.gitignore`），可由 Nginx 等静态托管，并将 `/api` 反向代理到后端。

## 配置 API 地址

开发环境默认通过 `vite.config.ts` 将 `/api` 代理到 `http://127.0.0.1:8765`。

```bash
VITE_API_BASE=http://your-api-host:8765 npm run dev
```

## 一体化模式（可选）

```bash
npm run build
cd .. && SERVE_FRONTEND=1 market-predictor web
```

访问 `http://localhost:8765/`。

## 目录结构

```
源码/
├── 入口.js              # 应用入口（导入样式 + 应用）
├── 应用.js              # 启动、导航、刷新、事件编排
├── 公共/
│   ├── 工具.js          # DOM、格式化、escapeHtml 等
│   ├── 主题.js          # 图表主题、缩放、配色
│   └── 状态.js          # overviewCache、channelLabels 等共享状态
├── 页面/
│   ├── 概览.js          # 概览·研判（价格图、LLM 研判、Prompt 预览）
│   ├── 回测.js          # 回测·资金（指标、净值、仓位、渠道对比）
│   ├── 模拟盘.js        # 模拟实盘
│   └── 归因.js          # 归因分析
├── 接口/                # API 客户端（客户端.js）
└── 资源/                # 全局样式（样式.css）
```
