# 系统说明（简版）

## 主路径

1. **采集 / 特征**：指数日线 → 特征表；若 Transformer 已启用且有 checkpoint，写入 `tf_proba_*`
2. **LLM 研判**：基本面 / 外盘 / 新闻 / 状态路由 → 日频涨跌平（量价不进 Prompt）
3. **组合**：`portfolio.allocation_mode = unified_sharpe` 六袖统一账本  
   - 进攻：沪深300 + 纳指  
   - 防守：黄金 + 国债  
   - 现金流：货币 + 逆回购  
   - LLM：组内 tilt + risk_on / risk_off；执行层降换手（EMA / 死区 / 渐进）
4. **费用**：可交易袖口按 `|Δw| × (commission + slippage)`；逆回购不计费
5. **展示**：只读 Web（概览 / 回测 / 模拟盘 / 归因）；前端不触发交易

## 运维

| 单元 | 作用 |
|------|------|
| `market-predictor-api` | FastAPI `:18765` |
| `market-predictor-frontend` | Vite / 静态前端 |
| `market-predictor-update.timer` | 周五 16:45：`update --once`（数据 + **增量**回测 + 模拟盘；默认禁止全量） |

配置真相源：`后端/配置/配置档/默认.yaml`。
