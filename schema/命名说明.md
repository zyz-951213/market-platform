# 统一库命名说明

库名：**金融市场数据**

## 三层结构（仅保留这些 schema）

| 层 | Schema | 内容 |
|----|--------|------|
| 公共 | `公共` | 原始仓物理表（原核心/资金流/宏观/财务/跨资产/主数据）+ 跨项目接口视图（如 `日行情`） |
| 行情增量 | `行情增量` | `同步水位`、`缺口登记` |
| 项目 | `行为分析` | market-agents；内含英文别名视图 `daily_bars` 等 |
| 项目 | `指数预测` | market-predictor；内含 `index_features` 等 |
| 项目 | `隐因子` | factor-latent；内含 `factor_values` 等 |
| 项目 | `微盘股研究` | micro-cap；档案表 + `mc_*` 英文视图 |
| 项目 | `特别处理研究` | st-legacy；专有表 + 共享视图 + `st_*` |

已删除：`核心市场数据` / `资金流` / `宏观经济` / `财务基本面` / `跨资产市场` / `主数据`，以及全部 `*兼容` schema。

## 行情增量（全库可衡量水位）

- `数据集登记`：要追踪的对象目录（schema.表 / 逻辑接口、水位列、责任方、更新策略、入口）
- `同步水位`：实测最早日/最后日/行数/体积/状态
- `水位总览`：登记 ⟕ 水位
- 初始化与重扫：`python3 后端/脚本/刷新全库水位.py`
- 日常更新结束后会自动重扫；单表回写用 `refresh_watermark`，读起点用 `get_watermark`

## 日行情

- `公共.日行情` = 微盘档案(≤2026-05-20) ∪ `公共.个股日行情文件` 增量(akshare/baostock)
- `公共.个股日行情文件` **只保留** `交易日期 > 2026-05-20`（档案段勿再灌入）
- `微盘股研究.mc_daily` / `特别处理研究.st_daily` → `公共.日行情`
- `行为分析.日行情` 仍为应用瘦表（口径独立）

## 日行情两套口径

| 口径 | 对象 | 用途 |
|------|------|------|
| **研究/公共** | `公共.日行情`（视图）= 微盘档案 ∪ 公共增量文件 | micro-cap / st / 隐因子等研究读此层 |
| **应用瘦表** | `行为分析.日行情`（物理表，OHLCV） | market-agents 策略与组合；勿与公共视图混当同一真源 |

英文别名：`微盘股研究.mc_daily` / `特别处理研究.st_daily` → `公共.日行情`；`行为分析.daily_bars` → 应用瘦表。

## 微盘日收益率

- 物理表：`微盘股研究.日回报`（回报独有列）
- `日收益率` / `mc_daily_returns` = `日回报` ⟕ `日行情`（OHLCV 不双存）
- DDL：`schema/微盘日收益率窄表.sql`

## 隐因子瘦身

- `隐维度标签`：d1–d9 标签只存一套；`隐空间坐标` 仅坐标+解释方差
- `因子取值`：主键为 `(证券代码, 交易日期)`，去掉 surrogate id / 重复索引
- DDL：`schema/隐因子瘦身.sql`

## 行为分析时序

- 物理表：`参与者活跃度`、`分钟日特征`（窄列，非 JSONB）
- `symbol_series` 视图由窄表拼 payload；ephemeral（日特征矩阵等）不再落库
- `策略净值`：`市场收益率` 已并入 `基准收益率`（二者历史完全相同）
- DDL：`schema/行为分析标的时序窄表.sql`

## 当前 DDL

空库或重建时按序执行（`schema/archive/` 为历史脚本，**勿**对生产再跑）：

```bash

psql -d 金融市场数据 -f schema/隐因子瘦身.sql
psql -d 金融市场数据 -f schema/隐因子因子取值视图.sql
psql -d 金融市场数据 -f schema/隐因子因子取值写触发器.sql
psql -d 金融市场数据 -f schema/微盘日收益率窄表.sql
psql -d 金融市场数据 -f schema/行为分析标的时序窄表.sql
```

## 更新控制台（方案 B）

- 视图：`行情增量.更新控制台`（数据最后日 / 期望最后日 / 新鲜度 / 可调度）
- 作业：`行情增量.更新运行` + `更新运行明细`（含水位是否推进）
- 后端：`后端/存储/更新注册表.py` + `更新作业.py`；API 需 `UPDATE_API_ENABLED=1`
- 前端：「更新」页可单表 / 勾选 / 按标签 / 全部可更新
- 字段映射：源与库字段不对齐时，在各 `update_*` 内做列映射与缺省计算，登记表只存调度元数据
